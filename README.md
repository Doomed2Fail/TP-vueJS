# TP Vue.js

TP1 et sa suite TP2-Suite sont dans la branche `TP1`. Les autres TP ont leur propre branche :

- [TP1 - Livres](https://github.com/Doomed2Fail/TP-vueJS/tree/TP1)
- [TP2-Suite - Suite du TP1](https://github.com/Doomed2Fail/TP-vueJS/tree/TP1/TP2-Suite)
- [TP1A - Budget](https://github.com/Doomed2Fail/TP-vueJS/tree/TP1A)
- [TP1B - Stock](https://github.com/Doomed2Fail/TP-vueJS/tree/TP1B)
- [TP1C - Notes](https://github.com/Doomed2Fail/TP-vueJS/tree/TP1C)
- [TP2 - Personnes](https://github.com/Doomed2Fail/TP-vueJS/tree/TP2)
- [TP3 - Taches](https://github.com/Doomed2Fail/TP-vueJS/tree/TP3)

Clique sur **TP1** pour afficher les dossiers `tp1` et `TP2-Suite`. Pour acceder aux autres TP, ouvre le menu des branches `TP1` en haut a gauche de la liste des fichiers, puis choisis la branche souhaitee. Tu peux ensuite ouvrir le dossier de ton choix.

Pour tester un TP, ouvre son dossier dans VS Code et lance son fichier HTML avec Live Server.
