# TP Vue.js

Chaque TP est dans une branche :

- [TP1 - Livres](https://github.com/Doomed2Fail/TP-vueJS/tree/TP1/tp1)
- [TP1A - Budget](https://github.com/Doomed2Fail/TP-vueJS/tree/TP1A)
- [TP1B - Stock](https://github.com/Doomed2Fail/TP-vueJS/tree/TP1B)
- [TP1C - Notes](https://github.com/Doomed2Fail/TP-vueJS/tree/TP1C)
- [TP2 - Personnes](https://github.com/Doomed2Fail/TP-vueJS/tree/TP2)
- [TP3 - Taches](https://github.com/Doomed2Fail/TP-vueJS/tree/TP3)

Clique sur un lien pour ouvrir le TP. Tu peux aussi changer de branche avec le menu `TP1` en haut a gauche de la liste des fichiers.

Pour tester un TP, ouvre son dossier dans VS Code et lance son fichier HTML avec Live Server.
